# 3Dモデル

2026-11-02時点の最新版は **BackRaised** です。

## 最新版

- [印刷用STL](new-dinasour-7chambers-t1p8-back-raised.stl) — 単位mm。
- [Fusionファイル](NewDinosaur_7Chambers_t1p8_BackRaised.f3d) — 最新形状。
- [元STL](new-dinasour-filled.stl) — 加工前の入力データ。

10 MB 以上のファイル（各版の Fusion ファイル `.f3d` と元STL）は `.gitignore` で除外しており、
リポジトリには入っていません。手元のフォルダーか、下記の Fusion クラウドにあります。

本体全長200 mm、7空気室、接続穴2 mm、外皮1.8 mm以上、隔壁1.5 mm。
BACK/LEGS間の壁は中央高さ60.2 mm、左側が低く右側が高い30°。
左脚・胴体の丸い部分との余裕を確認した版です。

Fusionクラウドにも `HAPT Lab / dino-touch-sensor / NewDinosaur_7Chambers_t1p8`
のv1として保存済みです。クラウド設計には非表示の旧版コンポーネントも含まれます。
