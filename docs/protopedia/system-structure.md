## 処理の流れ

1. **恐竜を押す**: TPU製の中空恐竜（外殻・隔壁1.5mm）のどこかを約1秒押して離します。
2. **空気が伝わる**: 7つの空気室は直径2.5mmの穴でつながっていて、圧力の変化がしっぽの先のセンサーまで伝わります。
3. **圧力を測る**: MPS20N0040DとHX710Bで、1秒に40回（24bit）計測します。
4. **特徴を取り出す**: 立ち上がり、減衰、半値幅、正負ピーク比など12個の特徴量をマイコン上で計算します。
5. **AIが推定する**: ROHM ML63Q2557のSolist-AIで HEAD / BACK / LEGS / TAIL に分類します。HEADとLEGSは専用モデルで再判定する2段階方式です。
6. **結果を表示する**: 基板のLCDに3秒表示し、USB UARTでPCへ送信します。
7. **恐竜が反応する**: ブラウザがWeb Serial APIで受信し、部位に応じた動画、画像、実測波形を表示します。

## 押して離すと、どんな波形になる？

![押して離したときの波形と12個の特徴量](/pic/8e0a9254-aa22-4266-b9c0-e1eade91a929.jpg)

恐竜を押すと、その空気室の空気が押し出されて圧力が上がります（正の山）。
手を離すと、形が元に戻ろうとして空気を吸い込むので圧力が下がります（負の谷）。
押す場所によって、この山と谷の形（立ち上がりの速さ、幅、戻り方）が変わります。

マイコンは圧力の「大きさ」ではなく、この「形」を12個の数にしてAIに渡します。

- 押したとき（正の山）から、立ち上がり時間、減衰時間、半値幅、面積÷高さ、最大傾き÷高さ、非対称度
- 離したとき（負の谷）から、立ち上がり時間、回復時間、半値幅、面積÷深さ
- 押すと離すのバランスとして、谷の深さ÷山の高さ、谷の面積÷山の面積

時間や比にすることで、押す強さが多少変わっても形の特徴が残るようにしています。

## 空気室のつながり

![7つの空気室のつながり](/pic/a514ea68-dfa6-47bd-b333-aef5be377892.jpg)

恐竜の中は7つの部屋に分かれていて、となりの部屋とは直径2.5mmの小さな穴1個でつながっています。
圧力センサーはしっぽの先に1個だけです。

センサー → ①しっぽ → ②右後ろ足 → ③右前足 → ④左前足 → ⑤左後ろ足 → ⑥背中 → ⑦頭（首）

しっぽを押すと空気の変化は穴を通らずにセンサーへ届き、頭を押すと6個の穴を通って届きます。
通る穴の数や部屋の大きさが場所ごとに違うので、圧力の伝わり方（波形の形）が変わります。
この違いをSolist-AIが覚えて、押した場所を当てます。

## ポイント

- 学習も推論もマイコンの中だけで完結（クラウドもPCも不要）
- 電源を入れると、60件の波形データからチップ上で自動学習（約0.5秒）
- 推定は前処理込みで約5ミリ秒
- 使用RAMは 8,576 / 16,384 bytes

## 回路図

![PneuTouch AIの配線図](/pic/6da4b60f-34c6-4d69-882b-443a0019dac6.png)

電子部品は、圧力センサーモジュールとROHMの評価ボードDT-EBML63Q2557の2つだけです。
恐竜の中には電子部品も配線もなく、しっぽの先から空気チューブで圧力をセンサーへ伝えます。

圧力センサーモジュールは、MPS20N0040Dが空気圧を電圧に変え、HX710Bが24bitのデジタル値にして1秒に40回出力します。
モジュールの4本線は評価ボードのCN3につなぎ、電源3.3VとGNDのほかに、SCKをP40、DOUTをP42へ接続します。
SPIなどの周辺機能は使わず、マイコンのGPIOで直接読み取ります。
センサーの電源はJP1の1-2を短絡して3.3Vにし、CN3には5Vの信号を入れません。

マイコンML63Q2557は、受け取った波形から12個の特徴量を計算し、Solist-AIで部位を分類します。
結果は基板のLCDに3秒表示し、FT2232H（USB-UART変換、115200bps / 8N1）を通してCN9のUSBからPCへ送ります。
PCのブラウザはWeb Serial APIで受信し、恐竜の反応動画や圧力の波形を表示します。
CN2のMCU-LINKは書き込みとデバッグ用で、開発時にだけ使います。
