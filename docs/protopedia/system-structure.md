## 処理の流れ

  1. **恐竜を押す** … TPU製の中空恐竜（外殻・隔壁 1.5mm）のどこかを約1秒押して離す
  2. **空気が伝わる** …
  7つの空気室が直径2.5mmの穴でつながっており、圧力変化が尻尾の先のセンサーまで伝わる
  3. **圧力を測る** … MPS20N0040D + HX710B で40回/秒計測（24bit）
  4. **特徴を取り出す** …
  立ち上がり・減衰・半値幅・正負ピーク比など12個の特徴量をマイコン上で計算
  5. **AIが推定** … ROHM ML63Q2557 の Solist-AI で HEAD / BACK / LEGS / TAIL
  に分類（HEADとLEGSは専用モデルで再判定する2段階方式）
  6. **結果を表示** … 基板のLCDに3秒表示し、USB UARTでPCへ送信
  7. **恐竜が反応** … ブラウザ（Web Serial
  API）が受信し、部位に応じた動画・画像・実測波形を表示
	
## 押して離すと、どんな波形になる？

![押して離したときの波形と12個の特徴量](/pic/8e0a9254-aa22-4266-b9c0-e1eade91a929.jpg)

  恐竜を押すと、その空気室の空気が押し出されて圧力が**上がり**（正の山）、
  手を離すと形が元に戻ろうとして空気を吸い込むので圧力が**下がります**（負の谷）。
  押す場所によって、この山と谷の形（立ち上がりの速さ・幅・戻り方）が変わります。

  マイコンは圧力の「大きさ」ではなく、この「形」を12個の数にして AI に渡します。

  - **押したとき（正の山）**：立ち上がり時間、減衰時間、半値幅、面積÷高さ、最大傾き÷高さ、非対称度
  - **離したとき（負の谷）**：立ち上がり時間、回復時間、半値幅、面積÷深さ
  - **押すと離すのバランス**：谷の深さ÷山の高さ、谷の面積÷山の面積

  時間や比にすることで、押す強さが多少変わっても形の特徴が残るようにしています。

 ## 空気室のつながり

![7つの空気室のつながり](/pic/a514ea68-dfa6-47bd-b333-aef5be377892.jpg)

  恐竜の中は7つの部屋に分かれていて、となりの部屋とは直径2.5mmの小さな穴1個でつながっています。
  圧力センサーはしっぽの先に1個だけです。

  センサー → ①しっぽ → ②右後ろ足 → ③右前足 → ④左前足 → ⑤左後ろ足 → ⑥背中 → ⑦頭(首)

  しっぽを押すと空気の変化は穴を通らずにセンサーへ届き、頭を押すと6個の穴を通って届きます。
  通る穴の数や部屋の大きさが場所ごとに違うので、圧力の伝わり方（波形の形）が変わります。
  この違いを Solist-AI が覚えて、押した場所を当てます。

  ## ポイント

  - 学習も推論もマイコンの中だけで完結（クラウド・PC不要）
  - 電源投入時に60件の波形データからチップ上で自動学習（約0.5秒）
  - 推定は前処理込みで約5ミリ秒
  - 使用RAMは 8,576 / 16,384 bytes
