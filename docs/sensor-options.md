# サンプル速度とHX711への変更案

調査日: 2026-09-20。HX710BのPhase 0を基準とし、以下は比較候補。変更の採用は未決定。

## 速度の比較

| 構成 | 公称値 / 資料の値 | 判断 |
|---|---|---|
| MPS20N0040D + HX710B | 10 / 40 SPS、40 SPSで約25 ms間隔 | 現在の4ピンモジュール。まず40で記録 |
| MPS20N0040D + HX711 | 内部発振で10 / 80 SPS、80 SPSで約12.5 ms間隔 | センサーを再利用できる低コストの比較案 |
| MS4525DO | 標準品の更新時間は典型0.5 ms、デジタル圧力14 bit | 高速化候補。実効取得レートは通信を含め検証 |

根拠: [S1 / S2 / S4](research-notes.md)。24 bitという表記は有効精度24 bitを保証しない。
MS4525DOの更新時間の逆数を、そのままPCへ欠測なく送れるサンプル速度とはしない。

恐竜は約20 cm。必要レートは外形だけでは決まらず、空気室の容量、穴径2.5 mm、
チューブ、押し方による過渡応答で判断する。80 SPSで7区画を識別できることは未実証。
同じ押し方で40 / 80 SPSを比較し、必要ならさらに高速な取得系で短い変化を調べる。

## 約20 cm・7区画・40 SPSでの予測

**実測前の見立て**: 大まかな部位差を得られる可能性はあるが、左右前後の足を含む
7区画の安定判定には厳しい条件と考える。成功率の数値を出せる根拠はまだない。
穴径2.5 mmでは区画間の圧力差が短時間で均される懸念がある一方、TPU壁の柔らかさや
区画容量が応答を遅くする可能性もある。外形と穴径だけでは時定数を確定できない。

40 SPSでは100 msに約4点、200 msに約8点。数msだけ現れる差は取り逃しやすく、
0.1～0.3秒ほど続く形状差なら取得できる余地がある。これらは説明用の時間幅で、実測値ではない。
HX711の80 SPSなら点数は倍になるが、部位の情報が元々ない波形を識別可能にはできない。

単純な伝搬距離による遅延と、空気室・オリフィスによる応答の遅れを分けて考える。
空気の音速を概算330 m/sとすると、自由な空気中の20 cmの伝搬時間は約0.6 ms。
これは実際の柔らかい恐竜内の応答時間の予測ではない。
根拠: [NASAの音速の説明](https://www.grc.nasa.gov/WWW/K-12/airplane/mach.html)。

また圧力センサー1個では、指が実際に触れた時刻を独立に観測できない。
到着時刻だけより、立ち上がり、ピーク、減衰、解放後の戻りという**波形の形**を比較する。
押す速さ・強さを変えても部位差が残るかを別試行で確認する。

初回は既存の40 SPSで取得し、HX711の80 SPSで比較する。
差が見えない原因を切り分ける必要が出たら、200～500 SPS程度を調査用の目標候補にする。
これは必要十分な速度の断定ではなく、より細かく観測してから下げられるかを試す方針。

## 指定されたAmazonのHX711基板

[KKHMF HX711 3個セット（B0822G1Y88）](https://www.amazon.co.jp/dp/B0822G1Y88)の
商品説明・画像を確認した。調査時の表示価格は3個で659円。価格・在庫は変動する。
これは圧力センサー素子を含まないADC基板。

掲載回路図ではRATEがGNDへ接続され、10 SPS設定になっている。
80 SPSは**HX711の15番RATEをDVDDへ設定**する。GNDへの接続を残したままDVDDへ短絡しない。
現物の0Ω抵抗・切替パッドと導通を確認して接続を変更する。
商品ページだけでは納品基板の版・抵抗位置まで保証できないので、部品位置の断定はしない。
ソフトのSCK周波数や読み出しパルス数ではRATEを切り替えられない。[S2]

## MPS20N0040Dのつなぎ替え

構成としては可能。HX710Bを取り外して配線を分離するか、センサー素子を別基板へ移す。
HX710BとHX711を同時にセンサーへ接続したまま運用する構成にはしない。
元モジュールのVCC/GND/SCK/DOUTのうちSCK/DOUTはデジタル通信なので、
**HX711のアナログ入力A+/A−へ接続する場所ではない**。

| センサー素子の信号 | HX711基板側 |
|---|---|
| ブリッジ励起＋ | E+ |
| ブリッジ励起− | E− |
| ブリッジ差動出力＋ | A+（または低ゲインを使う場合B+） |
| ブリッジ差動出力− | A−（またはB−） |

MPSの端子番号は実物の向き・型番末尾・基板配線と照合して決める。
型番の近いS版の参考資料[S3]だけで、手持ち素子のピン番号を断定しない。
元基板の給電経路も分離し、HX711のE+と別の電源出力を直結しない。

MCU側にはHX711のVCC/GND/DT/SCKを接続するが、3.3Vロジックを維持する。
電源共通型の基板を5Vで動かすとDOUTも5Vになる構成があるため、CN3へ直結しない。
まず3.3V給電時の実AVDD/E+、無負荷の差動電圧、入力共通モード範囲を確認する。
5Vのアナログ給電が必要ならDVDD分離やレベル変換を含む回路を別途決める。

## ゲインとファームウェアの違い

HX711では25パルス=A/128倍、26=B/32倍、27=A/64倍で、速度設定ではない。[S2]
HX710Bの27パルス=40 SPSという意味を引き継がない。

HX711の差動入力範囲は`±0.5 × AVDD / gain`。
例えば実AVDDが3.3Vなら128倍で約±12.9 mV、64倍で約±25.8 mV。
MPSの無負荷オフセットと押したときの振幅によっては、128倍では飽和する。
ゼロ補正はADC飽和後の信号を復元できない。64倍やB入力32倍も測定して選ぶ。
センサーの公称全圧力レンジを、このADC構成で全て測れるとは仮定しない。

80 SPS設定でも、平均化や固定delayでデータを間引かない。
非接触ノイズ・飽和・DOUTの準備完了間隔を記録して、実効速度と信号品質を比較する。

## さらに高速な候補

MS4525DOは差圧・ゲージ・絶対圧、電圧、I2C/SPIが型番で異なる。[S4]
例として`MS4525DO-DS3AI001DP`は3.3V・I2Cの差圧品を検討する際の候補型番。
部品単体と変換基板付き製品を区別し、電圧、圧力レンジ、端子、チューブ適合を確認する。
ここでは購入品・レンジを確定しない。HX711で不足した場合に、実測圧力を基に選ぶ。
