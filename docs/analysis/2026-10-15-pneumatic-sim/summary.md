## Physics caveat

tau_in = c / k is the wall's retardation (sink-in) time. For a homogeneous TPU wall it is largely a material property: making a wall thicker or thinner changes k and c together and leaves c / k unchanged. The mech_k_only row shows what stiffness alone buys (48 % 4-class / 31 % 7-class). The mech_tau rows (mech_tau4: 93 % 4-class / 53 % 7-class; mech_tau7_snap: 88 % 4-class / 80 % 7-class) show the upside only if geometry (domes, ribs, bellows, lattice-filled zones) can change the apparent sink-in time constant by 2x or more. That is what the 10/16 test pieces must measure: width_ms and decay_ms per press-face type.

Fluidic (channel) encoding is ruled out at 40 SPS: the star_graded channel delays are 4-15 ms, below one 25 ms sample (see the 1000 SPS table), so it would need kHz sampling.

## Notes and approximations

- Walls are quasi-static (massless): c x' = F - k x - A p; inertance and wall mass are ignored.
- Wall damping is direction dependent (c_out = c_out_ratio * c_in while the wall springs back). This "snap-back" term is an addition to the plan: with symmetric damping the best calibration residual is 0.124 versus 0.041, because a linear model cannot give both a 3.4x larger trough and a faster (50 ms vs 240 ms) recovery.
- Wall area, stiffness and finger force are only identifiable together (displaced volume A F / k and time constant c / k); individual values are not physical measurements.
- Gas is adiabatic and linearised (C = V / (gamma p0)) with no heat exchange; the sensor tube volume is folded into its chamber. The linearisation is stretched by the release snap-back: a 1 kHz check (5 presses per zone) found pressed-chamber minima of about -12 kPa (series_current), -25 kPa (series_thin) and -73 kPa (star_orifice), so star_orifice troughs are qualitative only.
- Channels use Poiseuille + orifice loss solved as one quadratic, quasi-steady (no inertance or entry development).
- Integration is linearly-implicit Euler at dt = 0.2 ms (channel time constants reach nanoseconds, so explicit RK4 would be unstable); 40 SPS samples are instantaneous values every 25 ms.
- Every zone uses one wall with the same area. The mech_* scenarios keep series_current connectivity and change per-zone k, c and c_out ratio (multipliers in parameters.json); mechanical_encoding is an alias of mech_tau4.
- Leg channel grading in star_graded follows series order RH, RF, LF, LH.
- Accuracy is computed on valid (complete) events only; INVALID events are reported separately.
- Calibration residual recomputed for the stored baseline: 0.041.
