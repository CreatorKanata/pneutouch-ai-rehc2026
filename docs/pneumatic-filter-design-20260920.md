# PneutouchAI — 隔壁・穴径で部位ごとの応答を作れるか

検討日: 2026-09-20（JST） / Copyright (C) 2026 Kanata the Kid Creator

## 現時点の回答

**穴径や流路の変更で、大きな波形差を作れる余地はある。空気圧のローパスフィルタという発想自体が失敗したとはいえない。**
現在確認できていないのは、HEADとLEGSを安定して見分けられるほど異なるフィルタ特性を、
今回の恐竜が持っているかという点である。

[既存65イベントの再分析](head-legs-waveform-analysis-20260920.md)では、追加記録の負側回復は
HEAD 140.6 ms、LEGS 139.1 msで、正規化した回復曲線も重なった。
正側の見かけの指数時定数も126.1 msと123.1 msで近い。
この値だけから「穴による遅れがない」とはいえない。手の動き、TPUの変形、空気の流れ、
センサーとADCの応答が重なった出力を見ているためである。

以前の「40 SPSでも特徴が出ている」という評価は、特定の記録で形状差を観測したという範囲に限る。
**穴径・隔壁がその差を作ったことや、HEAD/LEGSの差が押し方を変えても残ることは、未実証である。**

## 穴と空気室がフィルタになる仕組み

穴や細い流路は空気の流れに抵抗を与え、空気室は圧縮によって圧力変化を蓄える。
電気回路なら抵抗Rと容量Cに相当する。単純化した条件では、応答時間の目安は `τ ≈ R × C`。
細管の寸法を変えて応答の時間尺度を変える実験例がある。
[De Smet et al., 2025, §2.3](https://advanced.onlinelibrary.wiley.com/doi/10.1002/aisy.202400695)

```mermaid
flowchart LR
    A[入力側の圧力変化] --> R[穴・細い流路：流れへの抵抗 R]
    R --> C[空気室：圧縮・壁の変形に伴う容量 C]
    C --> Y[観測圧力：立ち上がりや戻り方が変わる]
```

これは仕組みを説明する概略で、7室の恐竜を1段のRCと同定した図ではない。
柔らかい空気室では壁の変形も圧力と容積の関係に関与する。
流路を変えても、他の部分の応答が支配的なら全体の変化は小さい。
逆に、流路が支配的な抵抗になれば形状の時間尺度を大きく変えられる可能性がある。

十分に長い円管の層流などの条件なら、流体抵抗は `R = 128 μ L / (π d⁴)` と近似できる。
同じ長さなら直径を半分にすると抵抗は16倍という計算になる。
**ただし、短い穴にそのまま16倍則を当てはめたり、今回の応答時間が16倍になると予測したりはしない。**
これは寸法の効果が小さいとは限らないことを示す理想化した例である。
[同論文の流路抵抗モデル](https://advanced.onlinelibrary.wiley.com/doi/10.1002/aisy.202400695)

オリフィス列の形状や配置で空気室への応答を変えた研究もあり、圧力差・流量・室の特性を含めて
設計・実測している。抵抗の順序を変えると、直列でも作動順が変わる例がある。
「穴を通る数が多ければ必ず一定量ずつ遅れる」という単純な説明では十分でない。
[Paez-Granados et al., 2021, §II-C～III-B](https://arxiv.org/html/2103.05332v1)
これらは加圧して動かす装置の研究であり、手で押す恐竜の分類性能を保証するものではない。

## 今回の設計で考えられること

[設計資料](product-design.md)では、隔壁厚1.5 mm、各穴径2.5 mm、接続順は
`センサー → 尾 → 右後足 → 右前足 → 左前足 → 左後足 → 背中 → 頭`。
空気室の実容量、印刷後の穴径・気密・TPUの圧力による膨らみは未測定。
STL/3MFは保存されているが、本検討で造形物の内部寸法を測定したわけではない。

| 仮説 | 現データとの関係 | 設計上の含意 |
|---|---|---|
| 2.5 mmの短い穴では均圧が速い | 可能性はあるが、流量・室容量がなく未確定 | 穴径だけでなく流路の長さも調整する余地 |
| 手の押す速度・解放速度が形状を支配する | 記録を変えると形状差が消え、振幅が逆転 | 同じ機械入力で流路の効果を切り分ける |
| TPU全体の変形や隣室への機械的な伝わりが大きい | 変形を独立計測していない | 空気経路だけでなく壁の変形・支持状態も見る |
| 共通のチューブ・計測系が曲線をなだらかにする | センサー直近の基準試験がない | 同じ入力を人形経由・直結で比較する |
| 意図しない連通や漏れがある | 保持中の力・変位が不明なので診断不能 | 既知の変位を保持し、圧力と形を記録する |

厚さ1.5 mmに対する径2.5 mmは、長い細管と呼べる形状ではない。
抵抗が小さすぎる可能性は検討すべきだが、寸法だけでその仮説を確定しない。
また、全区画に同じ穴径を使っても、容量や壁の硬さが異なるため同じRCにはならない。
7室は互いに影響するネットワークで、独立した同一フィルタ7個を単純につないだものでもない。

押している間に正側が基準へ戻り、離した後に負側が出る現象だけでは、ローパス作用を証明できない。
手が力を緩める、壁が変形する、空気が別室へ移る、漏れるなど複数の説明がある。
理想的に気密で全体積の減少を固定した系では、室間で均圧しただけで必ず元の圧力へ戻るわけではない。
今回のデータでは全体積や荷重を測っておらず、その条件を満たしているか分からない。

## 変更するなら、何を狙うか

**最初の候補は、頭と背中の間にある流路の抵抗を独立に調整できる構造。**
頭を押したときの幅・上昇・回復を変え、足の形状と離すことを狙う。
頭が末端にある現在の接続を利用した設計案だが、背中や足を押したときの頭側への流れも変わるので、
改造後は4クラス全部の波形を確認する必要がある。

| 変更候補 | 狙う効果 | 確認すべき点 |
|---|---|---|
| 頭への穴を小さくする | 頭側の均圧を遅らせる | 波形差と同時に振幅低下・長い復帰・穴の閉塞が起きないか |
| 長さのある細い流路にする | 長さと径で抵抗を調整しやすくする | 曲がり・潰れ・印刷寸法のばらつき |
| 頭側の空気室容量や壁形状を変える | 抵抗だけでなく圧力と容積の関係を変える | 押しやすさと機械的な戻りも変わる |
| 分岐ごとに違う流路を持つ配置 | 経路ごとに異なる時間応答を作る | 他室との連成を含めた実測。配置変更だけでの改善は保証しない |

全穴を同じ割合で小さくすると全体が遅くなるだけの場合もあるため、まず1か所の変更効果を見る。
表示は4分類なので、頭と足の差を大きくすることを先に狙い、4本の足をさらに分離する変更は後にする。

接触開始が未知という要件から、**単なる時間のずれだけを位置情報にしてはいけない。**
もし全く同じ波形が100 ms遅れて届くだけなら、その100 msは未知の接触時刻と区別できない。
幅、上昇と減衰の比、正負の形状など、波形内部に残る差を作る必要がある。
RCによって波形が広がる場合は、この種類の特徴を作れる可能性がある。

40 SPSでの設計目標を説明する例として、10→90%上昇が200 msと600 msなら約8間隔と24間隔になる。
これは分かれ方の例で、今回測定した値でも、推奨する完成品の時間仕様でもない。
目標は数msの差ではなく、数サンプル以上にまたがり、同部位の操作ばらつきを超える差である。
遅くしすぎると約1秒の操作や現行4秒タイムアウトに合わなくなる。

## 全体を作り直す前に行う試験案

これは今後の提案で、今回ユーザーに追加操作を求めたり、CADを変更したりはしていない。

1. **2室の小さな試験片を用意する。** 空気室・外壁を共通にして、間の穴または細管を交換できる構造にする。
   穴径を比較するなら2.5 / 1.5 / 1.0 mmなどを探索の開始案とし、実際に貫通している寸法を測る。
   最適径の推奨値ではなく、長さ違いの流路も比較に入れる。
2. **同じ押し込みを与える。** 一定ストロークの治具などで変位と動作時間をそろえ、同じ約1秒操作を繰り返す。
   弱・中・強の入力も別条件として比較する。必要なら評価時だけ接触時刻を同期記録する。
3. **共通の計測系の応答を確認する。** 同じ既知入力についてセンサー直結と試験片経由を比較し、
   40 SPSで試験片間の幅・戻り方の差が見えるか確認する。速すぎる場合の基準評価には高速取得を検討する。
4. **保持試験を別に行う。** 一定変位を保持し、圧力と形の変化を観察する。
   手押しの正負パルスだけから漏れやフィルタ作用を判断しない。
5. **差が確認できた条件を頭側の流路に適用する。** 4部位を混ぜた順で記録し、
   設計変更前後の特徴分布・採用率・判別結果・表示までの時間を比較する。

判定の目安は「穴や流路を変えると、同じ入力で再現する形状差が変わること」と
「その差が入力の強弱や速さの変化を超えて残ること」。ここまで確認してから分類器を合わせる。
現行の無効LEGS9件についてはソフトウェアの採用閾値という別の問題があるため、
機械構造の変更効果と混同しない。
