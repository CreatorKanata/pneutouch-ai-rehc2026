# MCU内蔵ADCによる高速圧力取得案

調査日: 2026-09-20。ユーザー提案を受けて追加。**実現候補だが、配線・部品・採用は未確定。**
HX710Bの40 SPSで不足する場合、HX711の80 SPS以外に、ML63Q2557の内蔵ADCを利用できる。
速度よりも、圧力センサーの微小差動信号を十分な分解能で取り込むアナログ回路が課題になる。

## 確認したADC仕様

根拠: [追加資料N8/N9](reference-catalog.md)、[既存資料H1](research-notes.md)。

| 項目 | 確認内容 | 根拠 |
|---|---|---|
| 方式・分解能 | 12 bit SAR、2ユニット、12入力チャネル | N8 PDF p.3、N9 PDF p.432 |
| 取得制御 | タイマトリガ、サンプル時間設定、2ユニットの同時変換 | N9 PDF p.432–436 |
| 最短変換時間 | 24 MHz時0.917 µs。ただし電源/基準電圧条件付き | N8 PDF p.28 |
| DTの3.3V条件 | VDD/VREFが3.3Vなら、資料上のADCクロック上限は16 MHz | N8 PDF p.28 |
| DTのアナログ入力 | CN6→基板上アナログ回路→P32/AIN0。ADC側0～3.3V | H1 PDF p.27、回路図 |
| 入力源 | ADC仕様は低い出力インピーダンスを要求。資料の目安は1 kΩ以下 | N8 PDF p.28 |

CPUの48 MHz、ADCの変換クロック、センサーのサンプリングレートは別の数値。
「最短約1 µs」から、DTで無条件に1 MSPSの圧力測定ができるとは言わない。
N9の変換時間式は`(SASHT設定値 + 15) / ADCクロック`で、放電・アンプ安定時間は別途必要。
200～1,000 SPS程度を比較実験の候補にするには、ADCの公称速度には余裕があると判断できる。
実効レート・精度・通信欠落は回路とファームウェアを組んで確認する。

ROHMの[製品ページ](https://www.rohm.co.jp/products/micon/solist-ai/ml63q2500-group/ml63q2557-nnngd_taping_-product)でも12 bit ADC搭載を確認した。

## センサーをそのまま4本でつなぎ替えることはできない

現在のモジュールのSCK/DOUTはHX710Bのデジタル端子。
DOUTをMCUのADCへ入れても圧力のアナログ値にはならない。
MPS20N0040D素子のブリッジ励起端子と差動出力を取り出し、HX710Bから切り離す必要がある。
実物の端子番号・回路・無負荷オフセットは未同定なので、具体的なはんだ箇所はまだ決めない。

提案する構成:

```text
MPS20N0040Dの差動出力
  → 計装アンプ等（差動増幅・オフセット調整）
  → 帯域制限・ADCを駆動できる出力
  → DTのCN6 / 内蔵ADC
  → タイマ取得・時刻/連番付きのPC記録
```

外付け回路は3.3V系の入力範囲に収め、例えば1.65Vを中心に圧力の増減を表す構成を検討する。
センサーの励起電圧、アンプの入力共通モード・出力振幅・ゲイン時の帯域・ノイズを照合する。
基準電圧と励起の関係も記録し、電源変動を圧力と誤認しない設計にする。
ブリッジ→計装アンプ→ADCという構成は[TIのブリッジセンサー資料](https://www.ti.com/lit/po/sbat003a/sbat003a.pdf)も参考になる。
具体的なアンプ型番・ゲインは、実測したオフセットと押下振幅を基に選ぶ。

## 12 bitで足りるか

0～3.3Vを12 bitで変換する場合、理想的な1カウントは`3.3 / 4096 ≈ 0.806 mV`。
仮に観測したい信号の変化が2 mVしかなければ、無増幅では約2.5カウントしか使えない。
これは説明用の振幅であり、恐竜の実測値ではない。

仮に100倍で適切に増幅できれば、ADCの1カウントはセンサー入力換算で約8.06 µV。
ただし実際はアンプ・ADCのノイズ、オフセット、非直線性、温度、飽和の影響が加わる。
ソフトウェアのゼロ補正は、増幅段やADCで飽和した波形を復元できない。
HX710B/HX711の24 bit表記とMCUの12 bitだけを比べて、利用可否を決めることもできない。

MCUの2チャネルでブリッジ両端を読んで引き算する方法も、アナログ増幅の代わりにはならない。
各チャネルの量子化・ノイズ・誤差を残したまま差を取るため、微小信号の分解能が不足しやすい。
高速取得後の平均化も、帯域を狭めるため短い部位差とのトレードオフになる。

## DTには既にアナログ入力回路がある

H1 PDF p.27–28の回路図と説明を確認した。CN6は単なるADC端子の引き出しではない。

| 基板上の機能 | 圧力測定での扱い |
|---|---|
| JP4: アナログ回路給電 | CN6回路を使う際の有効化が必要 |
| ACカップリング: 10 Hz以下を除去 | 圧力の保持や遅い過渡成分を失う。圧力比較ではDC経路を候補にする |
| JP7: ACカップリングをバイパス | 短絡時は1.65V中心のDC入力。外付けアンプの出力を整合させる |
| SW6: 約0.741～20倍のゲイン | 差動ブリッジ用計装アンプではない。資料はDCでは誤差を考慮し1倍を推奨 |
| 3次LPF: 10 kHz | 500 SPS等でのアンチエイリアスには帯域が広すぎる。追加の帯域制限等が必要 |
| 3段の反転増幅 | 入力に対しADC値の極性が反転。前処理・表示の符号を揃える |
| JP5: 信号線への24V印加 | 今回の低電圧圧力回路では使わず、開放を確認する |

**CN6に増幅回路があるからMPSを無条件に直結できる、とは判断しない。**
外付けの差動増幅・バイアス調整を行い、基板側はDC・1倍を基準候補として検証する。
CN6の電源ピンにはJP6等の設定も関係するため、接続前に信号ピン・給電電圧を測る。

H1にはADS8860系16 bit ADCのオプション実装もあるが、実装済みとは限らない。
デジタルセンサー用SPI等と競合するため、追加部品なしの内蔵ADC案とは分けて扱う。

## 参考コードと検証手順

`REF/samples/SA-ADC/SoftwareTrigger/`、`REF/samples/SA-ADC/TimerTrigger/`と
`REF/driver/inc/saAdc0.h`、`REF/driver/src/saAdc0.c`が取得処理の参考になる。
TimerTrigger例にはチャネル選択、タイマトリガ、ADC結果読取り、完了割り込みがある。
そのクロック/ピン初期値をDTへそのまま移さず、3.3V条件と既存の電源監視AIN1等の利用を確認する。

1. まず40 SPSで基準データを残す。センサーの励起、無負荷差動電圧、押下時振幅を測る。
2. 必要なゲイン・オフセット・帯域を決め、既知電圧で内蔵ADC経路を校正する。
3. 200/500/1,000 SPS等で記録し、飽和・ノイズ・ドリフト・欠測を確認する。
4. 取得時刻はタイマ/ADC側で付ける。PCの受信間隔を取得周期の代用にしない。
5. 帯域制限した高速データと40/80 SPS側を比較し、部位差が新たに見えるか評価する。
   ADCのフィルター差があるため、単なる間引きをHX710Bそのものの再現と呼ばない。
6. MCU/PCのデータ形式に取得方式・ADC分解能・レート・スケールを残し、モデルを再学習する。

**判断:** HX711は比較的簡単な80 SPS化の候補。内蔵ADCはアナログ回路の追加が必要だが、
数百SPS以上で圧力波形を調べたい場合の有力候補になる。HX711を必ず経由する必要はない。
現段階ではM1のHX710B取得を進め、速度が制約と分かった段階で必要帯域とノイズを基に選ぶ。
