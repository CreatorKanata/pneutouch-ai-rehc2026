# MPS20N0040D用のアンプ＋ADC

整理日: 2026-09-20。対象は圧力センサー1個で7区画のタッチ位置を推定する構成。
**回路図・IC資料に基づく検討であり、基板の実物確認・通電・波形測定は未実施。**
初期のHX710B / 40 SPS方針は維持し、高速取得が必要な場合の候補を整理する。

## 取得方式と役割

| 方式 | アンプとADCの担当 | 本プロジェクトでの位置付け |
|---|---|---|
| MPS20N0040D＋HX710B | HX710Bが増幅と24 bit A/D変換。10 / 40 SPS | 手持ち4ピンモジュールで基準データを取得 |
| MPS20N0040D＋HX711 | HX711が増幅と24 bit A/D変換。10 / 80 SPS | RATEの実配線変更を伴う比較案 |
| MPS20N0040D＋INA333＋MCU | INA333が差動増幅、ML63Q2557が12 bit A/D変換 | 200 / 500 / 1,000 SPS等で過渡波形を調べる候補 |

レート・HX711の変更条件は[取得方式の比較](sensor-options.md)、MCUの電圧・クロック・
分解能とCN6の回路は[内蔵ADC案](mcu-adc-option.md)を参照。
INA333基板にはADCやPC通信機能はない。7区画ごとにアンプを置く構成でもなく、
現在のセンサー1個に対して計装アンプ1個を使う。

```mermaid
flowchart LR
    MPS["MPS20N0040Dの差動出力"] --> INA["INA333：増幅・出力基準電圧"]
    INA --> LPF["帯域制限・ADC駆動"]
    LPF --> CN6["DT CN6：DC経路・ゲイン設定"]
    CN6 --> ADC["MCU内蔵ADC：タイマ取得"]
    ADC --> PC["UART：時刻・連番付きPC記録"]
```

元モジュールのSCK/DOUTはデジタル端子なので、INA333のVIN±へ接続しない。
センサー素子の励起±と差動出力±を同定し、HX710Bの入力・給電経路から切り離す。
裸のセンサーの物理ピン番号、励起電圧、許容圧力は未確定。近似型番から決めない。

## CJMCU-333の回路図から分かったこと

根拠は末尾のユーザー提供回路図。以下は**この図が実物と一致する場合**の読み取り。
下側の3個のオペアンプはINA333内部の説明図であり、外付けVREFバッファではない。

| 部品・回路 | 図に記載された内容 | 意味 |
|---|---|---|
| U1 | TPS73033DBVT、IN=VCC、OUT=3.3V、EN=VCC | 3.3Vレギュレーター |
| R3 | VCCと3.3V間の0Ω抵抗 | 実装されるとU1の入出力が直結される |
| U2 | INA333、V+=3.3V、V−=GND | 単電源の計装アンプ |
| R2＋R1 | 100kΩ可変抵抗と100Ω、RG端子間 | 増幅率の調整。R2は端子名が紛らわしいが、接続上はゲイン用抵抗 |
| R4・R5 | 3.3VとGND間の10kΩ＋10kΩ、中点をREFへ直結 | 公称1.65Vの基準電圧。バッファなし |
| C5・C6 | VIN− / VIN＋からGNDへ各0.1µF | 入力の帯域にも影響。センサーの出力抵抗と併せて評価 |

### 電源：R3の実装状態で給電方法が変わる

| 実物で確認した状態 | 給電の候補 | 3.3V端子の扱い |
|---|---|---|
| U1実装、R3未実装 | VCCへ5Vを入力して降圧 | U1の出力。別の3.3V電源と直結しない |
| R3実装、図どおり直結 | VCCへ安定した3.3Vを入力 | VCCと同じ電源ノード |
| U1 / R3の状態が不明、または図と違う | 実装・導通を確認してから決める | 印字だけで入力・出力を判断しない |

**R3を実装したままVCCに5Vを入れると、3.3Vと表示された配線にも5Vがかかる。**
INA333の出力もDTのADC入力範囲を超える可能性がある。
R3はバイパス用の実装オプションと推測するが、図にDNP（未実装）の指示はない。
回路図だけから「購入基板は5V給電でよい」と確定しない。

TPS730系の入力仕様は2.7～5.5Vだが、3.3Vを安定して出すには入力側に余裕が必要。
R3未実装のVCCへ3.3Vを入れても、正確な3.3V出力は保証されない。
また、VCCが無給電のまま3.3V端子へ外部電源を入れる方法は、U1への逆流を生じ得る。
根拠: [TPS730データシート](https://www.ti.com/lit/ds/symlink/tps730.pdf)、5.3 / 7.1.5 / 7.4節。

### VREF：生成回路はあるが、低インピーダンス化が課題

R4・R5の分圧は、無負荷なら`3.3 × 10 / (10 + 10) = 1.65V`。
その出力抵抗は`10kΩ || 10kΩ = 5kΩ`になる。
INA333のREFには低インピーダンスの駆動が必要で、直列抵抗が増えると
両入力に共通する変動を打ち消す性能（CMRR）が低下する。
この図の分圧直結では、IC本来のCMRRを前提にできない。
根拠: [INA333データシート](https://www.ti.com/lit/ds/symlink/ina333.pdf)、8.2 / 8.2.2.3節。

改良案は`3.3Vの分圧 → 単電源オペアンプのバッファ → INA333 REF`。
3.3Vで1.65Vを扱え、電圧フォロワーで安定する部品を選ぶ。型番・基板は未選定。
既存分圧とREFの間への挿入、または外部の低インピーダンス基準でVREFを駆動する方法を
実物の配線に合わせて決める。コンデンサーの追加だけではDCの出力抵抗は下がらない。

前の段階で未確認だったVREF端子と分圧回路は、今回の図で確認できた。
ただし、**VREFを1.65Vにしても無負荷VOUTが必ず1.65Vになるわけではない**。
センサーの無負荷差動オフセットも増幅されるため、実測してゲイン・基準電圧を調整する。
この基板のVREFはアンプの出力基準であり、MCUのADC基準電圧とは別。

### ゲインと帯域

低インピーダンスでREFを駆動し、線形動作しているときの基本式は
`VOUT ≈ G × (VIN+ − VIN−) + VREF`、`G = 1 + 100kΩ / RG`。
図では`RG = 100Ω + R2の有効抵抗`なので、公称の調整幅はおおむね2～1000倍。
抵抗端までの計算値は約1.999～1001倍だが、IC資料のゲイン範囲は1～1000倍であり、
最大位置の精度・抵抗公差を保証するものではない。[INA333資料・6.5 / 8.2.2.1節](https://www.ti.com/lit/ds/symlink/ina333.pdf)

まず低ゲインから始め、無負荷オフセットと押下・解放時の振幅を測って決める。
ソフトウェアでゼロ点を引いても、アンプやADCで飽和した波形は戻らない。
出力を0V / 3.3Vぎりぎりまで使う設計にせず、入力共通モードと出力振幅の余裕も確認する。

INA333の−3dB帯域は典型値で100倍時3.5kHz、1000倍時350Hz。
これはIC単体の条件付きの値で、基板全体の実効帯域ではない。
根拠: [INA333資料・6.5節の周波数特性](https://www.ti.com/lit/ds/symlink/ina333.pdf)。
ADCを1,000 SPSにしても波形の1kHz成分まで測れるわけではなく、
アンプ・入力コンデンサー・出力フィルター・標本化を合わせて設計する。

## DTへの接続方針

| 図の端子 | 接続・確認する内容 |
|---|---|
| J1-1 GND / J2-4 GND | センサー・アンプ・DTの共通GND |
| J1-2 VCC | 上記U1 / R3条件に従う電源入力 |
| J1-3 VIN− / J1-4 VIN＋ | 同定したMPS素子の差動出力− / ＋ |
| J2-1 VREF | 改良後の基準電圧。ADCの信号入力・ADC基準端子と混同しない |
| J2-2 VOUT | 帯域制限・駆動条件を満たしたうえでDTのアナログ入力経路へ |
| J2-3 3.3V | U1出力またはR3経由の電源。別電源との直結を避ける |

上記は回路図上の番号で、現物コネクターの見る向きは未確認。
センサーの励起電源は別途選定し、その消費電流と入力共通モードを確認する。
アンプが3.3V動作だからセンサーも無条件に3.3V励起でよい、とは断定しない。

CN6はMCUのADCピンそのものではなく、DTの増幅・フィルター回路を経由する。
[内蔵ADC案](mcu-adc-option.md)に従い、JP4給電、JP7のDC経路、SW6の1倍を基準に検討する。
JP5の24V印加は使わず、JP6等の給電設定を確認する。ADC側の範囲は0～3.3V。
DT上の3段反転による極性と、外付けアンプを含む総ゲインも記録する。
CN6を通さず別のAINへ接続する場合は、ピンの引き出し・競合・駆動条件を別途設計する。

DTの10kHz LPFだけでは数百SPSのアンチエイリアスに不十分。
必要な圧力帯域から追加フィルターと取得レートを選ぶ。高レート取得後に下げる場合も、
アナログ帯域制限とデジタル低域フィルターを適切に使い、単純間引きにしない。

## 実機で行う検証と記録

以下は**未実施の試験計画**。配線・回路図の評価と、動作確認済みという状態を分ける。

| 試験 | 方法 | 確認する結果 |
|---|---|---|
| 電源構成 | 無給電でU1・R3の部品と配線を確認し、VCC–3.3V間の抵抗を測る | R3経由の直結かレギュレーター経由かを同定。ブザー音だけで判定しない |
| アンプ単体 | MCUを外し、確認した電源方式で給電。電源、REF、既知の差動入力に対するVOUTを測る | 電源電圧・ゲイン・基準電圧が意図どおり。起動・停止時もADC範囲を逸脱しない |
| センサー接続 | 励起電圧、VIN±の対GND電圧、差動電圧、無負荷・押下・解放時VOUTを測る | 入力共通モード内で動作し、強い押下やゼロ点ずれでも飽和しない |
| ADC経路 | CN6設定を確認し、既知電圧と緩やかな変化を入力して電圧とADC値を比較 | スケール・極性・DC応答・ノイズが説明できる |
| 高速取得 | 200 / 500 / 1,000 SPS等で同条件の押下を記録 | MCU時刻と連番で実効レート・欠測を確認。帯域・遅延・部位差を評価 |

電源方式、基板版、センサー励起、REF実測、ゲイン、フィルター、ADC設定、ノイズと飽和を
測定記録に残す。取得方式を変更したデータはHX710Bデータと区別し、モデルを再学習する。
採用判断は7区画の別試行評価で行い、アンプの購入や高速化だけで分類成立とはしない。
