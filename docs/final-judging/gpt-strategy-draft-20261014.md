# PneuTouch AI — REHC2026 最終審査戦略・開発計画書

作成日：2026年10月14日 / 最終審査：2026年10月24日（土）

# 1. エグゼクティブサマリー

## 1.1 最終審査進出

PneuTouch AIは、32応募作品の中から選出された最終審査進出10作品の一つ。最終審査では3名の審査員によるオンラインプレゼン審査が実施され、受賞作品が決定する。本プロジェクトでは最優秀賞の獲得を目標とする。

## 1.2 PneuTouch AIとは

**One Sensor, Whole-Body Touch.**
柔らかいTPU製の恐竜内部を7つの空気室に分割し、区画間を直径2.5mmの穴で接続する。各部位を押すことで発生する圧力波形を尻尾先端の1個の圧力センサで取得し、特徴量からSolist-AIで接触位置を推定する。将来はぬいぐるみ、ソフトロボット、柔軟なロボット外装などへ展開できる触覚センシング技術を目指す。

## 1.3 中心戦略（差別化の3点）

- **A. 物理構造そのものが触覚情報を生み出す** — 空気室・隔壁・流路・オリフィスが接触位置に応じた圧力応答を作る。物理構造とAIの協調設計。
- **B. 小さなオンデバイスAIで柔軟な物体に触覚を与える** — 小さな特徴量とSolist-AIで分類。
- **C. 現場学習によって物体自身が触覚を獲得する** — 波形取得〜再学習をMCU上で完結させ、ユーザーが触れることで物体自身が新しい触覚を学習する。

## 1.4 最も重要なメッセージ

> センサを増やすのではなく、物体の構造を工夫する。
> これまでセンサではなかった柔らかい物体そのものを、Solist-AIで触覚センサへ変える。

# 3. ロームが求めるエッジAI

Solist-AIの特徴: 小規模NN、オンデバイス学習・推論、小RAM、低消費電力、設置場所・対象物に応じた学習。FAQでは異常検知専用ではないと明記。

PneuTouch AIは接触位置の教師あり分類にSolist-AIを使うが、「異常検知ではない」ことを独創性の中心に据えるべきではない（他作品にも例がある）。重要なのは、Solist-AIで従来と異なる触覚センシング方式を成立させたこと。

ロームにとっての価値: 小型MCUの新用途、センサを多数配置しにくい柔軟構造への適用、現場学習が必要なソフトロボット・玩具、低次元センサデータとエッジAIの組み合わせ、AIと物理構造の協調設計。

# 8. 改良戦略

## Strategy A：認識精度の実証（完成度）
未使用データテスト、複数ユーザー評価、混同行列、再現性、AIなし方式との比較。4クラス各20回=80回の未使用データ。目標: 未知データで90%以上（現時点の達成値ではない）。

## Strategy B：Solist-AI活用の進化（再ビルドなしの現場学習）
MCU内で特徴量計算 → FeRAM（2Mbit=256KiB）に特徴量+ラベル+CRCを保存 → PCからラベル指定 → 追加データ保存 → 再ビルドなしで再学習（逐次学習非対応ならまとめて再学習）。
デモ価値: 「新しい触り方を教えるためにファームウェアを書き込み直す必要がない」。

## Strategy C：自分の触覚を改善するAI（Self-Evolving Touch）
誤りやすい部位を特定し「右前足をあと5回押して教えてください」と要求 → 追加学習 → 独立評価で改善確認。苦手クラス選択はMCUの通常プログラム。

# 9. 将来構想：AI-Guided Pneumatic Design
オリフィス径・容積・流路長・壁厚を設計変数とし、分類精度評価から次の内部構造を提案する最適化ループ。Solist-AI単体でCAD生成は非現実的。最終審査では将来構想として紹介し、実装済みと誤認されないようにする。

# 13. 想定質疑応答（GPT）

- **Q1 なぜ1個のセンサで位置が分かる？** 7空気室を穴で接続しているので、押された場所で圧力の伝わり方が異なり、立ち上がり・減衰・ピークに差が出る。それをSolist-AIで学習。
- **Q2 なぜAIが必要？** 最大値だけでは区別できない場合がある。複数特徴の組み合わせで分類。AIなし簡易方式との比較で有効性を検証。
- **Q3 なぜSolist-AI？** ネットワークなしで小規模センサデータを学習・推論。柔らかい物体への組み込みに適する。オンデバイス学習で個体差・環境に適応。
- **Q4 7区画すべて分類できる？** 設計は7区画、ライブは4分類。7分類は次の目標。
- **Q5 押す強さが変わっても大丈夫？** 波形は変化する。正規化と複数の押し方を含む学習データを検討。強さ別の精度を分けて評価。
- **Q6 既存の空気圧触覚センサとの違い？** 既存研究はある。複雑な柔軟立体物内部に複数空気室を設計し、1センサ+小型オンデバイスAIと組み合わせた実装に挑戦。世界初とは主張しない。
- **Q7 PCが必要では？** 学習・推論はSolist-AI搭載マイコン。PCは可視化・データ管理・動画の補助。
- **Q8 実用化すると？** ぬいぐるみ、ソフトロボット、柔軟外装。耐久性、気密性、個体差、温度、複数同時接触の検証が必要。
