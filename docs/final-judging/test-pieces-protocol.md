# 試験片 ti1〜ti5 のテスト手順（Codex / 作業者向け）

作成日: 2026-10-21。この文書だけで作業が完結するように書いてある。
背景が必要なら [what-discriminates.md](what-discriminates.md) と [reprint-design.md](reprint-design.md) 3e 節。

## 0. 目的

PneuTouch AI は、TPU 製の中空恐竜を 1 個の空気圧センサー（MPS20N0040D + HX710B、40 SPS）で読み、押した部位を推定する。
計算と文献調査の結果、**空気の流路（穴の径・経路）では部位を見分けられず、見分けられるのは「押した場所の皮の力学」だけ**と分かった。
そこで「外形は同じまま、皮の内側の構造だけを変えると、圧力波形の形が変わるか」を 5 個の試験片で確かめる。

判定したいこと（go / no-go）:

- **go**: ti1 / ti4 / ti5 の 3 個が、押す強さを混ぜても、振幅を使わない 12 特徴量の最近重心法で **8 割以上**分かれる。
  → 「皮の裏のあそび」が設計変数になる。恐竜 v2 は外形そのまま・足の内側だけ変える方針で進む。
- **no-go**: 分かれない。→ 内部構造での改善は見送り、現行恐竜＋その場学習（teach モード）に集中する。
- 追加: ti2 または ti3 が ti1 と分かれれば、設計変数が 2 つになる。

## 1. 試験片

場所: `3d-models/test-pieces-internal/`（生成スクリプト `tools/make_test_pieces.py --set internal`）。
5 個とも外形は同じ（胴体の箱＋押す箱、押す面は平面 1.5 mm）。違うのは押す面の**内側**だけ。

| 番号 | ファイル | 内部 | 狙い |
|---|---|---|---|
| ti1 | `ti1-plain.stl` | なし | 基準 |
| ti2 | `ti2-thick-3.0.stl` | 内側から肉厚 3.0 mm | 硬さだけ変える対照 |
| ti3 | `ti3-ribs.stl` | 皮の裏に縦リブ（1.5 mm × 高さ 3、ピッチ 6） | 曲げ剛性と減衰 |
| ti4 | `ti4-gap-1.5.stl` | 皮の裏に **1.5 mm の隙間**＋第 2 の膜 1.5 mm | 押し込みの「あそび」1.5 mm |
| ti5 | `ti5-gap-3.0.stl` | 皮の裏に **3.0 mm の隙間**＋第 2 の膜 1.5 mm | あそび 3.0 mm |

用語:

- **押し面**: 小さい箱の、胴体と反対側の平らな壁。指で押す場所。
- **隙間（あそび）**: ti4/ti5 で押し面の内側にある空気の層。床の φ1.2 mm の穴で外気に通じている。皮がこの分だけ沈んでから第 2 の膜に当たり、そこから圧力が立ち上がる。
- **センサー口**: 胴体の箱から出ている短い筒（外径 5.7 / 内径 2.7 mm）。恐竜のしっぽの先と同じ。

印刷済みの個体に番号がない場合の見分け方は `3d-models/test-pieces-internal/README.md` と `how-to-identify.png`
（床の通気穴があるのが ti4/ti5、空走 1.5 mm が ti4・3 mm が ti5、一番硬いのが ti2、ti1 と ti3 は重さ 0.8 g 差か針金の止まる深さ）。

## 2. 機材と接続

- 試験片のセンサー口 → 恐竜と同じシリコンチューブ → MPS20N0040D + HX710B モジュール。
- モジュール → DT-EBML63Q2557（配線は恐竜と同じ: VCC→CN3-5、GND→CN3-11、SCK→CN3-12/P40、DOUT→CN3-10/P42）。
- ボード電源 ON、CN9 の USB を Windows PC へ。UART は **COM7**（FT2232H チャネル B、115200 baud / 8N1）。番号は PC で変わり得る。
- **ファームウェアの書き換えは不要。** 現行の `PneutouchAi`（`src/pneutouch-solist`）がそのまま生の圧力値 `PNEU1,seq,ms,raw` を 40 SPS で送る。
- LCD や画面に出る HEAD/BACK などの分類結果は恐竜用なので無視する。

## 3. 記録

### 3.1 共通ルール

- 5 個とも**同じ人が、同じ日に、続けて**記録する。
- 試験片は床を下にして机に置き、押し面を自分の方に向ける。反対の手で胴体の箱を軽く支える（胴体を握りつぶさない）。
- 押し方: **押し面の中央を親指の腹で「約 1 秒押して離し、3 秒待つ」を 10 回**。
- 強さは **弱 3 回・普通 4 回・強 3 回** を混ぜる（順番は任意）。弱でも指がはっきり沈む程度にする（弱すぎると波形が採用されない）。
- 順番: ti1 → ti4 → ti5 → ti3 → ti2（あそびの効果を先に見る）。
- 1 記録 = 1 個の試験片。記録の途中で片を替えない。

### 3.2 ブラウザー（学習ツール）で記録する場合

1. リポジトリ直下で `python tools/serve.py` を起動。
2. Chrome / Edge で <http://localhost:8000/learning-tool/> を開き、COM7 に接続。LCD に `READY` が出てから 2 秒待つ。
3. 「記録開始」→ 10 回押す → 「記録停止」→「CSV を保存」。
4. 次の片に付け替えて繰り返す。同じポートを 2 つの画面で同時に開かない。

### 3.3 CLI で記録する場合（同等）

```sh
python src/learning-tool/capture.py --port COM7 --output captures/test-pieces/ti1-plain-20261021-1.csv --duration 60
```

60 秒以内に 10 回押す。既存ファイルには上書きしない。

### 3.4 ファイル名（重要）

解析は**ファイル名の先頭 3 文字**で片を判別する。必ず `ti1`〜`ti5` で始める。

```text
captures/test-pieces/ti1-plain-20261021-1.csv
captures/test-pieces/ti2-thick-20261021-1.csv
captures/test-pieces/ti3-ribs-20261021-1.csv
captures/test-pieces/ti4-gap15-20261021-1.csv
captures/test-pieces/ti5-gap30-20261021-1.csv
```

CSV の列は `host_utc,seq,mcu_ms,raw,label`（学習ツール／capture.py が出す形式のまま）。

## 4. 解析

必要なもの: Python 3 と numpy・matplotlib（`requirements-analysis.txt`）。Mac なら `.venv/bin/python`。

```sh
python tools/analyze_test_pieces.py captures/test-pieces --out docs/analysis/2026-10-21-test-pieces
```

出力（`--out` の中）:

| ファイル | 内容 |
|---|---|
| `summary.md` | 片ごとの中央値（山の高さ、立ち上がり、山の幅、減衰、谷の幅、回復、谷/山、面積比）、一回抜き最近重心法の分離精度（全片とペアごと）、時間特徴の中央値比（2 倍以上に ✔）、押す強さとの相関 |
| `waveforms.png` | 片ごとの平均波形 ± 1σ（左: 生の counts、右: 山の高さで正規化） |
| `features.png` | 特徴量の散布図 |
| `events.csv` | 全イベントの特徴量と採用・除外理由 |

イベント検出と 12 特徴量は `tools/analyze_pressure.py` のものをそのまま使っているので、9 月の恐竜の数値と直接比べられる。
（参考: 恐竜ではしっぽ／背中の「谷の幅」が 129 / 295 ms で 2.3 倍。これが安定して当たっている部位の差の大きさ。）

## 5. 判定

`summary.md` の次の項目を見る。

1. 「分離」の **ti1 vs ti4、ti1 vs ti5、ti4 vs ti5** がそれぞれ 80% 以上 → go。
2. 「時間特徴の中央値の比」で、そのペアに ✔（2 倍以上）が付いているか。付いていれば「設計で時定数差が作れた」と言える。
3. 「押す強さとの相関」の |ρ| が 0.5 以下なら、その特徴は強さに頑健。
4. 各片の n（完全な波形）が 7 未満なら、除外理由を `events.csv` で確認し、必要なら取り直す（弱すぎ・速すぎが典型）。

結果は `docs/analysis/2026-10-21-test-pieces/` にそのまま残し、判定（go / no-go と根拠の数値）を
[plan-10days.md](plan-10days.md) の 10/16 行と [reprint-design.md](reprint-design.md) 3e 節に 1〜2 行で追記する。

## 6. よくある失敗

- 記録開始直後に押す → 基準値が決まらず最初の 1〜2 回が除外される。2 秒待つ。
- 押したまま長く保持する／連打する → 1 イベントとして扱えない。「1 秒押して離して 3 秒待つ」を守る。
- 胴体の箱を握ってしまう → 胴体の変形が波形に混ざる。
- チューブの差し込みが浅い → 漏れで振幅が落ちる。恐竜と同じ差し込み深さにする。
- ファイル名が `ti` で始まっていない → 解析対象にならない。
