参照番号は[調査資料一覧](research-notes.md)に対応する。配線は採用方針、実機動作は未検証。

## コネクターと電源

| 接続先 | 役割 | 今回の使用方針 |
|---|---|---|
| CN2 | SWDデバッグ | MCU-LINKを接続。ここから基板へ電源を供給しない |
| CN3 | 14ピンのデジタルセンサー用 | HX710BをGPIOで読み取る |
| CN6 | 増幅・フィルターを介したMCUのアナログ入力 | HX710B付き4ピンモジュールには使わない。高速取得の別案で検討 |
| CN8 | USB Type-C電源入力 | 電源専用。PCとのデータ通信はできない |
| CN9 | USB Type-C通信・電源 | PCからUART Bチャネルを開く |
| JP1 | センサー給電電圧の選択 | **1–2間をショートして3.3V** |
| JP8 | デバッグ中の電源保持 | 配布開発手順に従ってショート |

CN9にはデータ通信対応ケーブルを使う。外付けUSB-UART変換器は不要。
UARTのハードウェアフロー制御線は接続されていない。[H1 p.23]
CN3はMCU直結で保護バッファがないため、5V信号を入れない。[H1 p.26]

## MPS20N0040D + HX710Bの4ピンモジュール

- MPS20N0040D: 圧力をアナログ信号へ変換するセンサー。
- HX710B: ブリッジセンサーの微小信号を増幅・A/D変換し、デジタルで出力するIC。
- モジュールの想定端子はVCC/GND/SCK/DOUT。実物の印字とピン順を確認する。
- 入力はMCUのADCではなく、HX710BのDOUTをGPIOで受け取る。
- 初期出力は符号付きADC counts。圧力単位kPaへの校正は未実施。

HX710Bの電源仕様は2.6～5.5Vだが、これは**IC単体の仕様**。[S1 p.2–3]
購入モジュールの回路・レギュレーター・3.3V時の出力とノイズ・圧力レンジ・端子順は
実物とモジュール資料で確認する。型名だけから圧力換算係数や許容加圧量を決めない。

## 採用する配線

電源を切って配線し、接続前にCN3の電源が3.3Vであることを測定する。
CN3に標準MEMSボードが付いている場合は外す。

| モジュール | CN3のピン番号 | MCU / 用途 |
|---|---:|---|
| VCC | 5（8も同じ電源） | JP1で選択したPower Out=3.3V |
| GND | 11 | 共通GND |
| SCK / CLK | 12 | P40、GPIO出力 |
| DOUT / OUT / DAT | 10 | P42、GPIO入力 |

CN3-12/10は基板上ではSCK/MISOの信号名だが、今回は周辺SPI機能へ切り替えずGPIOを使う。
P42には基板側プルアップがある。コネクターの向きと1番位置はH1 p.33の図で確認する。

## HX710Bの読み出しで守ること

| 項目 | 仕様 / 方針 | 根拠 |
|---|---|---|
| 準備完了 | DOUTがLow。待機中SCKはLow | S1 p.4 |
| データ | 24ビット、MSB first、2の補数 | S1 p.3–4 |
| 範囲 | -8388608～8388607。両端は飽和の可能性 | S1 p.4 |
| 圧力・10 SPS | 1変換につき合計25パルス | S1 p.4–5 |
| 圧力・40 SPS | **合計27パルス**。初期採用 | S1 p.4–5 |
| 26パルス | HX710BではDVDD−AVDD測定。圧力ではない | S1 p.4 |
| High幅 | 最小0.2 µs、最大50 µs | S1 p.5 |
| Low幅 | 最小0.2 µs | S1 p.5 |
| パワーダウン | SCK Highが60 µsを超えると移行 | S1 p.5 |
| 安定待ち | 10/40 SPS時の公称値400/100 ms | S1 p.3 |

パルス数は**次の変換**の入力・レートを設定する。
実装では各High/Lowに2 µs程度の待機を設け、High中だけ割り込みを禁止する方針。
GPIOをLowへ戻した後に元の割り込み状態を復元する。
実際のHigh幅はロジックアナライザー等で測る。デバッグ停止でもHighが長くなる点に注意する。

最初の値は設定用として捨て、設定後500 msを安定待ちとする暫定方針。
1秒以上準備完了にならなければエラーを通知する。未接続時に架空の0を送らない。

HX711向けの「ゲイン選択」をそのまま流用しない。
HX710Bの26パルスは圧力入力ではなく、パワーダウン復帰時の設定保持もS1で確認する。

## サンプル周期と通信

初期設定は**公称40 SPS / UART 115200、8N1、フロー制御なし**。
1サンプル約25 msだが、実測のMCU時刻を保存し、公称値から時刻を捏造しない。
10 SPSも比較候補。コンセプト内の5 ms刻みのCSVは例であり、このADCの仕様ではない。
HX711への変更案と、その場合に異なる配線・レート設定は[sensor-options.md](sensor-options.md)を参照。

128点は40 SPSで約3.2秒分、16点のプリトリガーは約0.4秒分、残り112点は約2.8秒分。
反応動画の開始を早めたい場合は32/64点等も比較し、精度との関係を測る。

## 内蔵ADCによる高速取得の別案

ML63Q2557には12 bit ADCがあり、DTのCN6から基板上アナログ回路を介して利用できる。
MPS素子の差動出力には別途増幅・バイアス調整が必要で、HX710BのDOUTを接続する方式ではない。
基板のAC結合による10 Hz以下の除去、DC設定、ゲイン、3.3V時のADCクロック条件を
[内蔵ADC案](mcu-adc-option.md)に整理した。M1のHX710B配線は維持し、採用は実測後に判断する。

## ボード初期化の参考箇所

C1の`S_System/main.c`と`S_Driver/smpl_common.c`にPLL・WDT初期化がある。
`S_Output/PowerKeep.c`はP45の電源保持、`S_LCD/Lcd.c`はP72の外部リセット解除、
`S_Uartf/Uart1.c`はUARTF1とP70/P71の設定の参考になる。

配布`Uart1.c`の有効値は9600 baudで、115200用の値はコメントで示されている。
そのままコピーしてPCだけ115200にすると一致しない。クロック・UART設定をまとめて確認する。
RTEの`SystemCoreClockUpdate()`は初期値を代入する実装なので、PLL変更後の48 MHzを
SysTick設定に正しく反映させる必要がある。
